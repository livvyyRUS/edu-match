# EduMatch — информационная система для абитуриентов

**EduMatch** помогает абитуриенту 2027 года пройти весь путь поступления:
от выбора предметов ЕГЭ и вуза до приказа о зачислении. Система объединяет
каталог образовательных программ, интеллектуальный подбор по баллам ЕГЭ
и интересам (FastAPI + sentence-transformers) и пошаговый интерактивный план
поступления.

- **104 образовательные программы** бакалавриата и специалитета
- **7 университетов**: НИУ ВШЭ (Нижний Новгород), ННГУ им. Лобачевского,
  НГТУ им. Р.Е. Алексеева, НГЛУ им. Н.А. Добролюбова, ПИМУ, МФТИ,
  МГТУ им. Н.Э. Баумана
- **3 города**: Нижний Новгород, Москва, Долгопрудный
- **12 направлений подготовки**: IT, математика, инженерия, экономика,
  менеджмент, естественные науки, медицина, педагогика, психология,
  юриспруденция, гуманитарные науки, дизайн

## Возможности

### 🏠 Главная (`index.html`)
- Hero-блок с общим пазом проекта и быстрым переходом к разделам;
- блок «Всё для уверенного поступления» — ключевые сценарии сервиса;
- «Востребованные специальности» — 6 избранных программ с карточками;
- модальное окно программы с проходным баллом, местами, ЕГЭ и источниками.

### 📚 Каталог программ (`programs.html`)
- поиск по 104 программам: название, код специальности (например, `01.03.02`),
  вуз, ключевые слова;
- фильтры: предметы ЕГЭ (чипсы), направление, город, университет,
  ваш суммарный балл;
- сортировка: по проходному баллу ↑/↓, числу бюджетных мест, названию, коду;
- **избранное** — закладки хранятся в браузере (`localStorage`), есть режим
  «только избранные»;
- карточка программы: код, вуз, город, минимальный балл, бюджетные места,
  обязательные и вариативные ЕГЭ, ссылка на официальный источник.

### 🤖 Подбор программы (`assistant.html`)
- форма с быстрыми пресетами (IT, Математика/ML, Гуманитарные, Экономика,
  Право);
- произвольный набор предметов ЕГЭ с баллами (0–100);
- хобби и интересы свободным текстом (теги) — используются семантическим
  поиском;
- выбор города и вуза (выпадающие списки строятся из базы);
- **дополнительные баллы за индивидуальные достижения** задаются одним
  числом (0–10) в поле ввода;
- результат — персональная подборка с **кольцом совпадения в процентах**,
  отметками зачтённых/недостающих ЕГЭ и суммой баллов пользователя;
- опция «показывать программы с недостающими ЕГЭ» (со штрафом в рейтинге).

### 🗺️ План поступления (`roadmap.html`)
- **4 образовательных трека**: классический ЕГЭ, олимпиадный (БВИ),
  грантовый/стипендиальный, целевое обучение;
- каждый трек — таймлайн этапов с датами, чеклистами задач и советами
  экспертов; прогресс сохраняется в браузере;
- обратный отсчёт до старта приёмной кампании (20 июня 2027);
- календарь ключевых дат 2027 года **с предупреждением, что все даты
  примерные** (график утверждается приказом Минобрнауки);
- чеклист обязательных документов (паспорт, СНИЛС, аттестат, 086/у и т.д.);
- сбалансированный совет по числу предметов: 4-й предмет расширяет выбор
  программ, но высокие баллы по 3 предметам важнее средних по 4.

## Технологический стек

| Слой        | Технологии |
| ----------- | ---------- |
| **Frontend**  | Ванильные HTML / CSS / JavaScript (без сборки), шрифт Inter, светлая и тёмная темы |
| **Backend**   | Python 3.12, FastAPI, Uvicorn, Pydantic, NumPy |
| **ML-поиск**  | sentence-transformers: bi-encoder `paraphrase-multilingual-MiniLM-L12-v2`, reranker `mmarco-mMiniLMv2-L12-H384-v1` |
| **Данные**    | JSON-база `universities_programs.json` (104 программы) |
| **Инфраструктура** | Docker, docker-compose, uv (lock-файл зависимостей) |

## Архитектура

```
┌─────────────────────────── Docker-контейнер ────────────────────────────┐
│                                                                         │
│  Браузер ──► HTML/CSS/JS (index, programs, roadmap, assistant)          │
│                 │                                                       │
│                 ▼ GET /match?ege=math:92,...                            │
│            FastAPI (main.py, порт 8000)                                 │
│                 │                                                       │
│                 ▼                                                       │
│            Matcher                                                      │
│            ├── 1) bi-encoder: эмбеддинг запроса × эмбеддинги 104        │
│            │      программ (косинусная близость)                        │
│            ├── 2) формула: 0.45·semantic + 0.30·ege_coverage            │
│            │      + 0.25·ege_scores + штрафы/бонусы                     │
│            └── 3) cross-encoder переранжирует top-20:                   │
│                   итог = 0.6·score + 0.4·CE                             │
│                 │                                                       │
│                 ▼                                                       │
│            universities_programs.json (база программ)                   │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

Приложение **монолитное**: FastAPI одновременно отдаёт статические страницы и
JSON-API, поэтому CORS не требуется — фронтенд и бэкенд на одном origin.

ML-модели скачиваются **на этапе сборки образа** и кэшируются внутри него:
контейнер стартует быстро и работает без доступа к huggingface.co.

## Как работает интеллектуальный подбор

Для каждой программы считается итоговый score:

```
score = w_sem · semantic + w_cov · ege_coverage + w_scr · ege_scores
                                + корректирующие штрафы/бонусы
```

1. **`semantic` (вес 0.45)** — косинусная близость эмбеддинга запроса
   («Мои ЕГЭ: …, Интересы: …, Город: …») и эмбеддинга программы
   (название + направление + предметы + описание), посчитанных
   многоязычным bi-encoder'ом.
2. **`ege_coverage` (вес 0.30)** — покрытие предметов пользователя:
   `0.75 · доля закрытых обязательных + 0.25 · доля закрытых вариативных`.
3. **`ege_scores` (вес 0.25)** — качество баллов: средний балл релевантных
   предметов сравнивается с порогом `minScore / egeCount`
   (`0.5 ± запас/50`, клип 0…1).
4. **Корректировки:**
   - недостающий обязательный предмет — `score × 0.5` (или программа скрыта);
   - недобор до проходного — мягкий штраф до `× 0.35`;
   - запас над проходным — лёгкий бонус до `× 1.15`.
5. **Reranker**: top-20 кандидатов дополнительно прогоняются через
   cross-encoder, который видит пару «запрос + программа» целиком;
   финальный score = `0.6 · score + 0.4 · CE`.

Предметы в запросе можно передавать и по-русски («русский», «матан»,
«физика») — нормализуются таблицей синонимов.

## Быстрый старт

### 🐳 Docker (рекомендуется)

```bash
docker compose up --build
# или напрямую:
docker build -t edumatch .
docker run -p 8000:8000 edumatch
```

Откройте <http://localhost:8000>.

> Первая сборка скачивает ~1 ГБ ML-моделей — дальнейшие сборки идут из кэша.

### 🐍 Локально (uv)

```bash
uv sync
uv run uvicorn main:app --host 0.0.0.0 --port 8000
```

### Локально (pip)

```bash
python -m venv .venv && source .venv/bin/activate
pip install fastapi "uvicorn[standard]" numpy pydantic sentence-transformers
uvicorn main:app --host 0.0.0.0 --port 8000
```

При запуске сервис кодирует всю базу программ (~10–30 секунд на CPU) и затем
отвечает мгновенно.

## API

| Метод | Эндпоинт   | Описание |
| ----- | ---------- | -------- |
| GET   | `/health`    | Готовность сервиса и число программ в базе |
| GET   | `/programs`  | Все программы (JSON) |
| GET   | `/match`     | Персональный подбор |
| GET   | `/docs`      | Swagger UI с интерактивной документацией |
| GET   | `/`, `/index.html`, `/programs.html`, `/roadmap.html`, `/assistant.html` | Страницы сайта |

### Параметры `GET /match`

| Параметр | По умолчанию | Описание |
| -------- | ------------ | -------- |
| `ege`       | —      | Предметы и баллы: `math:92,russian:88,informatics:95` (можно по-русски) |
| `hobbies`   | —      | Интересы через запятую: `python,алгоритмы` |
| `city`      | —      | Точный фильтр по городу |
| `university`| —      | Подстрока названия вуза |
| `top_k`     | `5`    | Сколько программ вернуть |
| `w_semantic` / `w_ege_coverage` / `w_ege_scores` | `0.45` / `0.30` / `0.25` | Веса формулы (нормализуются) |
| `use_reranker` | `true` | Включить переранжирование cross-encoder'ом |
| `allow_missing_required` | `false` | Показывать программы с недостающими ЕГЭ (со штрафом) |
| `rerank_pool`  | `20` | Размер пула для reranker'а |

### Пример

```bash
curl "http://localhost:8000/match?ege=math:92,russian:88,informatics:95&hobbies=python,алгоритмы&top_k=3"
```

```json
[
  {
    "program": { "id": 2, "title": "Прикладная математика и информатика", "...": "..." },
    "score": 0.8123,
    "semantic_score": 0.74,
    "ege_coverage": 1.0,
    "ege_scores": 0.8,
    "rerank_score": 0.91,
    "user_total": 275,
    "score_margin": 23,
    "missing_required": []
  }
]
```

> Параметр `bonus` (доп. баллы за индивидуальные достижения, 0–10) фронтенд
> принимает от пользователя и отображает в сводке результатов; задел для
> учёта бонуса прямо в формуле score.

## Модель данных

Запись программы в `universities_programs.json`:

```json
{
  "id": 1,
  "city": "Нижний Новгород",
  "university": "НИУ ВШЭ",
  "code": "01.03.01",
  "title": "Математика",
  "profile": "Фундаментальная и прикладная математика",
  "description": "…текст описания…",
  "ege": ["russian", "math", "informatics", "physics"],
  "egeCount": 4,
  "requiredEge": ["russian", "math"],
  "optionalEge": ["informatics", "physics"],
  "minScore": 252,
  "budgetPlaces": 20,
  "direction": "math",
  "form": "fulltime"
}
```

- `requiredEge` — обязательные предметы, `optionalEge` — по выбору
  (в конкурс идут лучшие);
- `egeCount` — сколько предметов засчитывается в конкурсную сумму;
- `minScore` — проходной балл прошлой кампании (справочно);
- описание содержит ссылку на официальный источник вуза.

## Особенности реализации

- **Без сборки фронтенда**: страницы — статические HTML/CSS/JS, FastAPI
  отдаёт их напрямую через `FileResponse` и `StaticFiles`.
- **Состояние в браузере**: тема оформления (`edumatch_theme`), избранное
  (`edumatch_favs`), прогресс по плану (`edumatch_roadmap_progress`) —
  регистрация не требуется.
- **Отказоустойчивый фронтенд**: каталог работает и без бэкенда
  (данные дублируются в `js/data.js`); подбор показывает понятную ошибку,
  если API недоступен.
- **Production-образ**: непривилегированный пользователь, healthcheck,
  CPU-сборка PyTorch (образ без CUDA-пакетов), `HF_HUB_OFFLINE=1`
  для старта без сети.

## Важные оговорки

- ⚠️ **Все даты приёмной кампании 2027 — примерные.** Точный график
  утверждается приказом Минобрнауки РФ и публикуется вузами; на странице
  «План» это явно подчёркнуто.
- Данные по проходным баллам и местам — справочные, собраны из открытых
  источников вузов; перед подачей документов сверяйтесь с официальными
  правилами приёма.
- Процент совпадения — оценка пригодности программы, а не гарантия
  поступления.

## Идеи развития

- учёт параметра `bonus` (индивидуальные достижения) прямо в формуле score;
- автоматическое обновление базы программ парсером сайтов вузов;
- расширение базы на другие города и магистратуру;
- сохранение результатов подбора и сравнение программ «лицом к лицу»;
- Telegram-бот поверх API `/match`.
